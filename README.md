# 🧪 Chemistry Live — Backend & Shared Contracts

Интерактивная Kahoot-подобная соревновательная викторина по химии в режиме реального времени. Данный репозиторий содержит полную базу данных PostgreSQL для Supabase, SQL-миграции, политики безопасности RLS, конфигурацию Realtime-подписок, а также кроссплатформенные TypeScript-типы, константы подсчета очков и Zod-схемы валидации.

## 🗄️ База данных и SQL Миграции

### Таблицы (`001_initial_schema.sql`)
1. **`profiles`** — профили пользователей, преподавателей и организаторов викторин.
2. **`quizzes`** — квизы (название, описание, автор, флаг публикации).
3. **`questions`** — вопросы со сложностью (`easy`, `medium`, `ultra_hard`), лимитом времени и балльной сеткой.
4. **`answer_options`** — 4 варианта ответов к каждому вопросу с привязкой к фирменным цветам Kahoot (красный, синий, желтый, зеленый).
5. **`game_sessions`** — игровые комнаты с 6-значным цифровым PIN-кодом, текущим состоянием (`lobby`, `question_active`, `question_review`, `leaderboard`, `game_over`, `cancelled`).
6. **`players`** — участники сессии (никнейм, суммарный счет, текущая серия верных ответов, онлайн-статус).
7. **`player_answers`** — зафиксированные ответы игроков (выбранный вариант, время реакции в мс, заработанные баллы).
8. **`game_results`** — финальный протокол игры (итоговое место, правильные ответы, суммарный счет).

### Безопасность RLS (`002_rls_policies.sql`)
- На всех 8 таблицах включен **Row Level Security**.
- Анонимные игроки могут свободно подключаться к сессии по PIN-коду и отправлять ответы.
- Чтение вопросов и вариантов ответа открыто для участников активных игр.
- Создание и редактирование квизов защищено авторизацией автора/организатора.
- Административный и серверный доступ осуществляется через `service_role`.

### Supabase Realtime (`003_realtime_config.sql`)
В публикацию `supabase_realtime` включены таблицы:
- `game_sessions` — трансляция смены статусов раундов, старта вопроса, показа лидерборда.
- `players` — мгновенное обновление списка участников в лобби и набранных очков.
- `player_answers` — индикация активности ответов игроков в реальном времени.

Все три таблицы сконфигурированы с `REPLICA IDENTITY FULL` для доставки полных изменений состояния.

### Сид-данные («Каучук и резина») (`004_seed_questions.sql`)
Тематическая викторина содержит ровно **20 научно выверенных вопросов** на русском языке:
- **10 вопросов категории Easy** (1000 очков, 20 секунд):
  - Природный латекс бразильской гевеи
  - Мономер изопрен (2-метилбутадиен-1,3)
  - Суть процесса серной вулканизации
  - Открытие Чарльза Гудьира (1839 год)
  - Сера как классический сшивающий агент
  - Синтез бутадиенового каучука академика С. В. Лебедева
  - Каучуки как эластомеры
  - Образование твердого эбонита при избытке серы
  - Термопластичность и клейкость сырого каучука
  - Гуттаперча как природный транс-изомер
- **5 вопросов категории Medium** (1500 очков, 30 секунд):
  - Цис-1,4-стереоизомерия натурального каучука
  - Хлоропреновый каучук (неопрен) и 2-хлорбутадиен-1,3
  - Оксид цинка (ZnO) и стеариновая кислота как активаторы вулканизации
  - Высокая газонепроницаемость бутилкаучука
  - Моно-, ди- и полисульфидные ковалентные мостики (-S_x-)
- **5 вопросов категории Ultra Hard** (2000 очков, 45 секунд):
  - Катализаторы Циглера — Натта (TiCl4 + AlR3) для СКИ-3 (>98% цис-звеньев)
  - Термодинамический эффект Джоуля — Гофмейстера (конформационная энтропийная упругость)
  - Стехиометрия и бифункциональный механизм реакции Лебедева (дегидрирование + дегидратация)
  - Озонная деструкция диенов по механизму Криге (1,3-диполярное присоединение с распадом молозонида)
  - Радикальная пероксидная вулканизация насыщенных эластомеров (СКЭП, силиконы)

## ⚡ Механика подсчета очков (Scoring)

Баллы начисляются по классической формуле скорости:

$$\text{SpeedFactor} = 1 - \frac{\text{ResponseTimeMs}}{\text{TimeLimitSeconds} \times 1000 \times 2}$$

$$\text{SpeedMultiplier} = \text{clamp}(\text{SpeedFactor}, 0.5, 1.0)$$

$$\text{BaseAward} = \text{round}(\text{BasePoints} \times \text{SpeedMultiplier})$$

$$\text{StreakBonus} = \min(\text{Streak}, 5) \times 100$$

$$\text{TotalPoints} = \text{BaseAward} + \text{StreakBonus}$$

- За неверный ответ присуждается **0 очков**, а серия (streak) сбрасывается до нуля.
- При ответе на первой миллисекунде игрок получает 100% базовых очков.
- При ответе в последнюю секунду игрок получает не менее 50% базовых очков.

## 🛠️ Настройка и запуск

### 1. Переменные окружения
Скопируйте пример файла конфигурации:
```bash
cp .env.example .env
```
Заполните ключи доступа Supabase:
- `SUPABASE_URL`
- `SUPABASE_ANON_KEY`
- `SUPABASE_SERVICE_ROLE_KEY`

### 2. Применение миграций в Supabase
Выполните миграции по порядку через Supabase SQL Editor или Supabase CLI:
```bash
supabase db push
# или последовательно исполните файлы из supabase/migrations/
```

### 3. Проверка типов TypeScript
```bash
npm install
npm run type-check
```
